# Generador Seguro de Contraseñas

Proyecto académico desarrollado para la UIDE.

## Descripción
El programa permite generar contraseñas aleatorias utilizando letras mayúsculas y minúsculas, números y símbolos. El usuario puede seleccionar una longitud entre 8 y 50 caracteres.

## Tecnologías
- Python 3
- Visual Studio Code
- GitHub

## Funcionalidades
1. Mostrar un menú.
2. Solicitar la longitud de la contraseña.
3. Validar que la longitud sea correcta.
4. Generar una contraseña segura.
5. Mostrar la contraseña generada.
6. Permitir generar nuevas contraseñas.
7. Finalizar el programa.

## Estructuras utilizadas
- Condicionales `if / elif / else`.
- Bucle `while`.
- Comprensión de listas.
- Funciones.
- Manejo de excepciones `try / except`.

## Archivos
- `generador_contrasenas.py`: código principal.
- `diagramas/`: diagramas de flujo del proyecto.

## Ejecución
Desde la terminal:

```bash
python generador_contrasenas.py
```
